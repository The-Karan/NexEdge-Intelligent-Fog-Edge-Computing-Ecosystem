# Data and attribution

This release uses deterministic synthetic sensor readings, labeled as such throughout the interface. No external dataset is bundled or attributed.

Before adding real data, verify its source, license, consent/privacy constraints, preprocessing steps, and data dictionary. Potential sources named for future research—not included in this project—are PhysioNet (physiological data), UCI repositories, FAO/ISRIC soil resources, and public IoT security datasets. Cite the exact dataset version and license in this file before distribution.
