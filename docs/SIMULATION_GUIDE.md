# Simulation guide

Sign in with the demo account. Use **Simulate readings** in Healthcare, Soil, or Live Sensor Monitoring to add persisted readings. In Security, `CARD-DEMO-4821` grants access; other credentials are denied and recorded locally. In the IoT Lab, add components or load the Smart Soil project, then run the supported JavaScript simulation. Use Reports to create an archive entry and download an HTML report or CSV data.

The lab does not compile arbitrary Arduino firmware or electrically simulate arbitrary circuits. It faithfully labels this boundary and supports a documented set of demonstration behaviors.
